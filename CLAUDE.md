# CLAUDE.md — правила разработки BARBER HOUSE

Учебный одностраничный сайт премиального барбершопа. Утверждённое ТЗ и план по этапам — в [PROJECT_PLAN.md](PROJECT_PLAN.md).

## Постоянные правила

1. Перед изменением кода изучай существующую структуру.
2. Выполняй только поставленную задачу.
3. Не переписывай рабочие компоненты без необходимости.
4. Используй семантический HTML, чистый CSS и JavaScript.
5. Все изменения должны учитывать мобильную адаптивность.
6. Не добавляй зависимости без разрешения.
7. Не придумывай данные реальных клиентов.
8. Не публикуй сайт и не выполняй `git push` без подтверждения.
9. После каждого этапа перечисляй изменённые файлы и результаты проверок.
10. Не утверждай, что проверил сайт в браузере, если не делал этого.
11. Если требования неоднозначны, сначала задавай вопросы.
12. Следуй утверждённому PROJECT_PLAN.md.

## Контекст проекта (уже решено в PROJECT_PLAN.md)

- **Стек:** HTML5, CSS3, JavaScript. Без фреймворков, сборщиков и npm.
- **Файлы:** `index.html`, `css/style.css`, `js/main.js`, `assets/`. Порядок блоков в CSS и JS совпадает с порядком секций на странице.
- **Пути только относительные** (`css/style.css`, а не `/css/style.css`): сайт будет жить в подпапке на GitHub Pages. Исключение — ссылка «На главную» в `404.html`.
- **Имена файлов:** латиница, строчные буквы, через дефис.
- **CSS:** mobile-first, БЭМ-классы, цвета и шрифты только из CSS-переменных в `:root`.
- **Данные:** никаких выдуманных отзывов, имён сотрудников, адресов и телефонов. Заглушки должны явно выглядеть как заглушки.
- **Изображения:** только со свободной лицензией, каждое записывается в `CREDITS.md`.
- **Кнопки записи** помечаются атрибутом `data-booking`. Ссылка на мессенджер задаётся в одном месте — `CONFIG` в `js/main.js`.
- **Git:** один коммит на этап, после проверки. Пункты чек-листа этапа отмечаются в PROJECT_PLAN.md.

## Проверки

- Локальный сервер: `python -m http.server 8000` → http://localhost:8000 (или Live Server в VS Code).
- HTML: валидатор W3C (validator.w3.org/nu).
- Консоль браузера без ошибок и без 404.
- Ширины для проверки адаптива: 320, 375, 768, 1024, 1440, 1920 px.
