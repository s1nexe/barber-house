# BARBER HOUSE

Учебный одностраничный сайт премиального барбершопа. Все данные на сайте демонстрационные.

**Стек:** HTML5, CSS3, JavaScript, без фреймворков и сборщиков.

**Статус:** в разработке. План и техническое задание описаны в [PROJECT_PLAN.md](PROJECT_PLAN.md).

## Как запустить локально

Вариант 1: открыть папку в VS Code и запустить расширение **Live Server** (кнопка «Go Live» внизу справа).

Вариант 2: запустить встроенный сервер Python из папки проекта и открыть http://localhost:8000:

```bash
python -m http.server 8000
```
