# BARBER HOUSE

Учебный одностраничный сайт премиального барбершопа. Все данные на сайте демонстрационные.

**Сайт:** https://s1nexe.github.io/barber-house/

**Стек:** HTML5, CSS3, JavaScript, без фреймворков и сборщиков.

План и техническое задание — в [PROJECT_PLAN.md](PROJECT_PLAN.md), источники фото и шрифтов — в [CREDITS.md](CREDITS.md).

## Что внутри

- Разделы: первый экран, о нас, услуги, цены, команда, галерея, контакты.
- Адаптивная вёрстка от 320 px, мобильное меню, фильтр услуг по категориям, лайтбокс галереи, анимации появления.
- Сайт работает и без JavaScript; анимации отключаются при системной настройке «уменьшить движение».
- Lighthouse (мобильный режим): 100 / 100 / 100 / 100.

## Как запустить локально

Вариант 1: открыть папку в VS Code и запустить расширение **Live Server** (кнопка «Go Live» внизу справа).

Вариант 2: запустить встроенный сервер Python из папки проекта и открыть http://localhost:8000:

```bash
python -m http.server 8000
```

## Запись

Кнопки «Записаться» открывают окно записи: имя, телефон и услуга (список берётся из прайса).
Форма демонстрационная: поля проверяются, но данные никуда не отправляются и не сохраняются —
после проверки появляется сообщение «Демонстрация: заявка не отправлена».

Ссылка на мессенджер задаётся в одном месте — `CONFIG.bookingUrl` в начале `js/main.js`.
Если она заполнена, в окне записи появляется ссылка «Написать в Telegram».
Без JavaScript кнопки просто ведут к разделу «Контакты».

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` (папка `/`).
Файл `.nojekyll` отключает обработку Jekyll: файлы отдаются как есть.
